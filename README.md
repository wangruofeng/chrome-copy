# X 正文一键复制

一个轻量的 Chrome 扩展，在 X（Twitter）每条帖子的操作栏中增加复制按钮，一次点击即可复制当前帖子的正文纯文本。

## 功能

- 支持 `x.com` 和 `twitter.com`
- 支持时间线、帖子详情页和页面内动态导航
- 只复制当前外层帖子的正文
- 保留正文换行、表情、话题标签、@用户和链接的可见文字
- 成功、无正文和失败状态均有即时反馈
- 支持键盘操作、焦点提示和屏幕阅读器状态播报
- 不收集、不上传、不保存浏览内容

## 安装

1. 下载或克隆本项目，并确认目录中存在 `manifest.json`。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目根目录 `chrome-copy`。
6. 打开或刷新 X 页面。

修改扩展源码后，需要在扩展管理页点击本扩展的“重新加载”，再刷新 X 页面。

## 使用

打开 X 时间线或任意帖子详情页。每条帖子底部的操作栏会出现复制图标，点击后：

- 复制成功：图标短暂变为绿色勾选，并提示“已复制”。
- 帖子无正文：图标短暂显示红色警告，并提示“该帖子没有可复制的正文”。
- 复制失败：提示“复制失败，请重试”。

复制内容只有当前帖子的正文。作者、发布时间、帖子链接和被引用帖子的正文不会被加入剪贴板。

## 权限与隐私

扩展仅在以下地址注入本地内容脚本：

- `https://x.com/*`
- `https://twitter.com/*`

扩展没有后台脚本，不申请存储、标签页、网络请求或身份权限。帖子正文只在用户点击按钮后写入本机剪贴板，不会发送到任何服务器。

## 本地开发

需要 Node.js 20 或更高版本。

```bash
npm install
npm test
```

重新生成扩展图标：

```bash
npm run icons
```

项目不需要打包或构建，Chrome 直接加载项目根目录即可。

## 已知限制

- 纯图片、视频或投票等没有正文的帖子不会复制媒体描述。
- X 属于第三方页面，其 DOM 结构调整后可能需要同步更新选择器。
- 浏览器或系统策略禁止写入剪贴板时，扩展会尝试兼容回退；两种方式都失败时会显示错误提示。
- 当前版本不支持自定义复制格式、批量复制、快捷键或右键菜单。

## 项目结构

```text
manifest.json            Chrome Manifest V3 配置
src/post-content.js      当前帖子正文识别与提取
src/content.js           按钮注入、复制和动态页面监听
src/content.css          按钮与反馈样式
icons/                   扩展图标
tests/                   自动化测试
```
