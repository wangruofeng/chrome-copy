# X 帖子正文一键复制扩展设计

## 目标

开发一个基于 Chrome Manifest V3 的轻量扩展，在 X（Twitter）时间线和帖子详情页中，为每条帖子提供“一键复制正文”按钮。

首个版本只复制用户点击的当前帖子的可见正文纯文本，不包含作者、发布时间、帖子链接或引用帖子的正文。

## 使用体验

- 扩展在 `x.com` 和 `twitter.com` 页面自动运行。
- 每条帖子的操作栏中增加一个复制按钮，与回复、转发、点赞和分享操作并列。
- 点击按钮后，将当前帖子的正文写入系统剪贴板。
- 复制成功时，按钮短暂切换为勾选状态，并通过无障碍状态文本提示“已复制”。
- 复制失败或帖子没有正文时，显示明确且短暂的错误提示，不写入剪贴板。
- 按钮支持鼠标、键盘和触摸操作，并提供清晰的焦点样式和中文无障碍标签。

## 内容提取规则

1. 以用户点击的按钮所属 `article` 元素作为当前帖子边界。
2. 只读取该帖子自身的第一个顶层 `[data-testid="tweetText"]`。
3. 若候选正文位于当前帖子的引用帖子容器中，则排除该候选。
4. 使用 `innerText` 获取页面可见文本，以保留自然换行以及表情、话题标签、@用户和链接的可见文字。
5. 对结果执行首尾空白清理，但不合并正文内部换行。
6. 当前帖子没有正文时返回空结果，不回退复制引用帖子或媒体描述。

## 架构

扩展不引入前端框架或构建系统，使用可直接加载的原生 HTML、CSS 和 JavaScript：

- `manifest.json`：声明 Manifest V3、内容脚本及两个站点的访问范围。
- `src/content.js`：发现帖子、注入按钮、定位当前帖子正文、执行复制和反馈状态。
- `src/content.css`：按钮、悬停、焦点及状态反馈样式，尽量继承 X 当前主题颜色。
- `icons/`：扩展图标资源。
- `tests/`：使用 Node 内置测试工具验证可抽离的正文选择与注入防重逻辑。
- `README.md`：简体中文安装、使用、权限说明、已知限制及测试方法。

内容脚本使用 `MutationObserver` 监听 X 的动态页面更新，并批量扫描尚未处理的帖子。每个已注入操作栏带有扩展专属标记，避免重复插入按钮。页面卸载时无需保存状态。

## 剪贴板与错误处理

优先使用 `navigator.clipboard.writeText`。若该能力不可用或被拒绝，则使用页面内临时 `textarea` 配合 `document.execCommand('copy')` 作为兼容回退。

所有失败都限制在当前按钮：不会修改帖子正文、不会阻止 X 原有交互，也不会将正文发送或保存到任何位置。状态反馈结束后恢复为默认复制图标。

## 权限与隐私

- 仅匹配 `https://x.com/*` 与 `https://twitter.com/*`。
- 不申请后台脚本、存储、网络请求、标签页或用户身份权限。
- 不采集、上传或持久化用户浏览内容。

## 测试与验收

自动化测试至少覆盖：

- 普通帖子正文的提取与换行保留。
- 包含引用帖子时只返回外层正文。
- 外层正文为空时不回退到引用正文。
- 同一操作栏不会重复注入按钮。
- Manifest 结构、内容脚本路径和站点匹配规则有效。

人工验收覆盖 X 首页时间线、帖子详情页、主题切换、页面内导航、无限滚动、键盘触发、连续点击及无正文媒体帖子。由于 X 的 DOM 属于第三方实现，选择器变化是主要兼容风险；代码应集中定义选择器，并在 README 中明确该限制。

## 非目标

首个版本不提供复制格式设置、作者或链接拼接、引用帖子复制、批量复制、右键菜单、快捷键、设置页面、数据统计或浏览器商店发布流程。
